# DSH Desktop · Evolith 插件快速上手

插件版本：0.18.16。新用户直接安装，旧用户先卸载再安装。

## 一、新用户安装

1. 打开 DSH Desktop，点击左侧 **插件 → 添加插件**。
2. 在“包名或地址”中粘贴以下仓库地址，点击 **安装**：

   ```text
   https://github.com/dataelement/dsh-memory-bridge
   ```

3. 安装完成后，**完全退出并重新打开 DSH Desktop**。

## 二、老用户更新

1. 等当前回复结束，在 **插件** 中找到旧记忆插件（包名 `dsh-memory-bridge-profile`），点击 **卸载**。
2. 点击 **添加插件**，粘贴上面的 GitHub 仓库地址，重新安装。
3. 完全退出并重新打开 DSH Desktop。

**聊天记录和工作区会保留，不用重新创建。**

## 三、连接记忆服务

使用前请连接公司内网或 VPN。

1. 打开 [Evolith 后台](http://192.168.106.20:28292/workbench)，注册或登录，复制自己的 **访问密钥**。
   **旧版 Memory 的账号密码、有效访问密钥都可以继续使用。**
2. 打开 DSH **设置 → 记忆**，填写：

   | 配置项 | 填写内容 |
   | --- | --- |
   | 服务器地址 | `http://192.168.106.20:28292` |
   | 访问密钥 | 你自己的 Memory 访问密钥 |

3. 点击 **保存连接配置 → 检查连接**，看到“连接正常”即可。

原来使用 `28192` 的用户，请改成 `28292`。**无需填写 Group ID，也无需配置记忆模型的 API Key。**

## 四、开始使用

**Evolith 默认开启**，可直接正常聊天；可在会话输入框旁随时关闭或重新开启；切换服务或密钥后，已有会话需要重新确认开启。

- 同账号下，各工作区和会话共享记忆，不同账号相互隔离。
- 开启后，本会话的消息、回复及工具调用/结果（包括已有历史）会发送到公司记忆服务器。
- 关闭的会话不会向记忆服务器上传会话内容。

## 常见问题

- **提示已安装**：先卸载旧插件，再重新安装。
- **仓库无权限或下载失败**：确认电脑能访问 GitHub，且已获得该仓库的访问权限。
- **连接失败 / Not Found**：确认已连内网，地址使用 `28292`，不要带 `/workbench`。
- **密钥无效 / 401**：从新版后台重新复制自己的有效访问密钥。
