# Evolith · DSH Desktop 插件安装指南

为 DSH Desktop 的对话提供记忆管理。当前版本：**0.18.19**。

## 新用户安装

1. 打开 DSH Desktop，进入 **插件 → 添加插件**。
2. 粘贴下面的 GitHub 仓库地址，点击 **安装**：

   ```text
   https://github.com/dataelement/dsh-evolith
   ```

3. 安装完成后，**完全退出并重新打开 DSH Desktop**。
4. 按下面的步骤连接记忆服务。

## 已安装用户更新

1. 等当前回复结束，在插件列表找到旧版记忆插件（包名 `dsh-memory-bridge-profile`），点击 **卸载**。
2. 点击 **添加插件**，粘贴上面的仓库地址，重新安装。
3. 完全退出并重新打开 DSH Desktop。

**原有工作区和聊天记录会保留，不用重新创建。** 更新后检查一次记忆服务连接即可。

## 连接记忆服务

公网可直接访问；公司内网也可使用下面列出的内网地址。

1. 打开 [Evolith 后台](http://110.16.193.170:51030/workbench)，注册或登录。
2. 复制你账号下的 **访问密钥**。
3. 在 DSH Desktop 中打开 **设置 → 记忆**，填写：

   | 配置项 | 内容 |
   | --- | --- |
   | 服务器地址 | `http://110.16.193.170:51030` |
   | 访问密钥 | 从 Evolith 后台复制的个人访问密钥 |

4. 点击 **保存连接配置**，再点击 **检查连接**。显示“连接正常”后即可使用。

**不需要填写 Group ID，也不需要配置记忆模型或模型 API Key。** 记忆服务的访问密钥与聊天模型的 API Key 不同。

公司内网可填写 `http://192.168.106.20:8001`，后台页面为 `http://192.168.106.20:8001/workbench`。两个入口连接同一个服务，账号和记忆相同。

已有旧版 Memory 账号的用户，可以继续使用原账号密码和有效访问密钥。原服务器地址为 `28192` 或 `28292` 的，请更新为上述公网或内网地址；保存后检查连接，并在已有会话中重新开启 Evolith。

## 开始使用

- **Evolith 默认开启**。可以在会话输入框旁随时关闭或重新开启；手动关闭的状态会保存。
- 同一个账号下，各工作区和会话共享记忆。不同账号之间隔离。
- 每轮回复的分支按钮后，会按本轮记录显示盾牌或闪电；点击后，右侧只展示这一轮标记为可能有帮助的记忆。没有记录的轮次不显示图标，两类收益都有时只显示一个组合图标。
- 切换服务器或访问密钥后，已有会话需要重新开启 Evolith。

**数据范围：** 开启后，本会话的用户消息、模型回复和工具调用/结果（包括已有历史）会发送到记忆服务器。关闭后停止后续上传；重新开启时会同步关闭期间的公共对话。已上传的数据和已插入上下文的历史记忆不会因关闭开关自动删除。

## 常见问题

| 问题 | 处理方法 |
| --- | --- |
| 提示插件已安装 | 先卸载旧版，再通过仓库地址重新安装。 |
| 仓库无权限或下载失败 | 确认电脑能访问 GitHub，并有该仓库的访问权限。 |
| 检查连接显示 Not Found | 地址填写 `http://110.16.193.170:51030`（或内网 `http://192.168.106.20:8001`），不要加 `/workbench`。 |
| 提示记忆访问密钥未填写、无效或已过期 | 到后台复制有效访问密钥，在 **设置 → 记忆** 更新、保存，再检查连接。 |
| 访问密钥显示 `****` | 表示已经保存。留空保存会保留原密钥。 |
| 更新后仍是旧界面 | 完全退出 DSH Desktop 后重新打开，仅刷新页面可能不会加载全部更新。 |
